# Scope

**The reference is generated and is never authored.** There is no step at which anybody transcribes anything into it, and a single hand-maintained corner would destroy the only property that makes it worth having over prose.

**It carries no case content.** No value an analyst entered, no count of what exists, no evidence, no name of a customer the reader does not reach. What a field *accepts* is structure; what somebody put in it is a case.

**Absence is not an answer.** Something missing from the reference does not mean the application lacks it. Where a part is not described, the reference says so and says where to look.

# Design

## One description, three consumers

The reference is derived from the same description that checks a write, draws a screen and reads an import. It cannot disagree with what it describes, because there is nothing separate to disagree with.

## Two doors

**The open door** needs no session, no account and nothing configured. It carries only what is true of every install of a version: the collections, what a row of each is made of, what each field accepts, the vocabularies the product ships, and the kinds of thing a report can be built from.

**The door behind a session** describes this install: everything the open door carries, plus what the install acquired — the operator's own vocabularies, templates and layouts.

What shipped is distinguishable from what was added, because the two are supported differently and change for different reasons.

## Configuration naming a customer is scoped to that customer

Where an operator adds a template, layout or vocabulary value particular to one customer, it carries that customer and reaches only analysts who reach them.

Configuration is not exempt from the no-case-content rule. A template written for one customer names them by existing, so an unscoped reference would disclose the customer list to anybody with a session.

## It answers the question asked mid-investigation

The question is *what can I put here, and what does the system mean by it*, asked by somebody who will not read source and cannot wait.

So it is reachable from the application, in the language the application is being used in, and it presents what a field means rather than only its name and its kind.
