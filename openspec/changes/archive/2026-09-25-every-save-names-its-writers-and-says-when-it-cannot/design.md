# Scope

**A save names whoever the store accepted the words from, whichever process makes it.** Where no acceptance names anybody, it stores nothing.

**An install runs one process**, so the unsaved state reaches every connection holding the document, and no state crosses between processes.

**A section's removal is its own attributed act**, stored as whoever removed it.

# Design

**Every save names the writers the store holds current acceptances for on that record**, the latest accepted last, and runs as the prose role under the same policies. It removes those acceptances in the same act, so one act is named once; an acceptance a document holds that the store no longer holds has lapsed, swept or not, and its words are told lost. A save refused because the report was sent removes what it held, and tells the words lost where they were written after the send.

**Words held unsaved are said to be.** A failed save tells every connection holding the document on this process, once; a save that stores them says they are saved; a lapsed acceptance says they are lost. A connection opening the document, or asking its state again, is told at once. The screen draws one notice per document with the text to copy and locks nothing, raises a dialog once for words given up, and asks before a route change or an unload while words are unsaved, since a connection that has ended can be told nothing.
