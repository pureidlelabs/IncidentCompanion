# Scope

**A case the database does not hold is not a deleted case.** Its artefacts leave the install on the install's record of its deletion, or with the rebuild that removes a demonstration. Bytes of a case no database holds and no record says was deleted stay until an operator removes them.

**Inside a case the database holds, the database is the authority on what the case holds.** Bytes its evidence records and sent reports do not name go at the next start, whichever copy is newer.

# Design

**The record of a deletion is what removes a case's directory.** It outlives the case by requirement, so a stop between the deletion and the removal of its artefacts is finished at the next start. A database that does not list a case is read as knowing nothing about it.

**A demonstration's removal leaves no record, so the rebuild removes what it deletes.** Its artefacts go once the rebuild commits, from the directory the server writes, so the one-shot that runs the rebuild shares that directory.

**What an earlier layout left outside any case directory is removed at start.** Nothing reads it, and nothing else would ever remove it.

**Storing bytes a case already holds counts as storing them now.** The grace that protects an upload whose row has not yet committed is measured from that moment, not from the first time the bytes arrived.

**Which figures a document places has one definition**, the one render draws from, and the start and the archive read a sent report's figures through it.
