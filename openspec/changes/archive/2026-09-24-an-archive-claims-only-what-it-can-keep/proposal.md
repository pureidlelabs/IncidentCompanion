# An archive claims only what it can keep

## Why

The non-author review of the archive lane found two sentences the code does not make true. The case-archive specification said an imported preserved document carries no live indicator "whatever the archive carried", while the containment pass leaves an analyst's written prose as it is, in a sent report and so in one read in. And it said the people an archive is handed to are told that sealing is what protects it, with nothing telling them.

## What Changes

- **case-archive**: an imported preserved document is held to the rule a report sent here is held to: what the install generates is contained, and an analyst's own prose is theirs. Whether an analyst's prose should also be contained is put to the maintainer.
- **case-archive**: a scenario for the unsealed archive, whose analyst is told that whoever holds it can change it without that showing.

## Impact

- The export dialog says so when the analyst leaves the archive unsealed.
