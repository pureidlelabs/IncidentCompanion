# Scope

**A save names whoever the words were accepted from, whichever process makes it.** Where no acceptance names anybody, the process holding no writer stores nothing.

**A section's removal is its own attributed act**, stored as whoever removed it.

# Design

**A save with no writer here names the writers the store holds current acceptances for on that record**, the latest accepted last, and runs as the prose role under the same policies. It leaves those acceptances to the save that took them, so that save is still refused as sent, or stores, rather than finding its record gone.

**Words held unsaved are said to be.** A failed save tells every connection holding the document, once; a save that stores them says they are saved; a lapsed acceptance says they are lost. A connection opening the document, or asking its state again, is told at once. The screen draws one notice per document with the text to copy and locks nothing, raises a dialog once for words given up, and asks before a route change or an unload while words are unsaved, since a connection that has ended can be told nothing.
