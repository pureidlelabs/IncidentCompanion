# Every save names its writers, and says when it cannot

## Why

A save of prose with no writer on the instance making it ran as whoever asked and wrote no change row or audit line, so words relayed from another instance could reach the record, a sent report included, naming nobody (#1240). Words the install could not store were held in memory and lost when the last reader left, with a server log line the only trace, and the analysts writing them were never told (#1241).

## What Changes

- **live**: an instance storing words it holds no writer for names the writers the store accepted them from, as the accepting instance would, and stores nothing where no acceptance names anybody. The section deletion stays its own attributed act.
- **live**: every analyst with a document open is told while the install holds its words unsaved, with the text to copy and nothing locked; told when a save stores them; told when they can no longer be stored; and asked before leaving with them unsaved.

## Impact

- A new frame from the install to a connection carries the state of the words it holds unsaved.
- A save with no writer and no acceptance on record stores nothing, where it stored as whoever asked.
